### Proyectos Principales

#### 📊 Análisis Exploratorio: Censo de Vivienda y Gasto (El Salvador)
Procesamiento y limpieza de datos demográficos y económicos del censo nacional de El Salvador.
* Tratamiento de valores nulos, filtrado y estructuración de conjuntos de datos con **Pandas**.
* Identificación de patrones de gasto y características de vivienda.
* **Tecnologías:** Python, Pandas.

#### 🏗️ Sistema de Gestión de Ventas (Clean Architecture)
Aplicación de ventas desarrollada aplicando principios de Arquitectura Limpia para mantener desacoplada la lógica de negocio.
* Separación del código en capas (Modelos, Controladores y Vistas).
* Mapeo objeto-relacional (ORM) para la gestión y persistencia de datos.
* Diseño de interfaz gráfica enfocada en usabilidad.
* **Tecnologías:** C++, Visual Studio, Entity Framework / ORM.

#### 💻 Módulo de Ventas e Interfaz de Usuario
Desarrollo del frontend de escritorio y flujo de autenticación para un sistema de comercialización de tecnología.
* Maquetación visual de pantallas de login y catálogo de productos.
* Modelado y conexión con base de datos relacional para consulta de inventario.
* **Tecnologías:** Python, Java, MySQL.

#### 🌐 Prácticas de Alta Disponibilidad e Infraestructura
Laboratorios orientados a arquitectura distribuida y entornos virtualizados.
* Pruebas de resiliencia y tolerancia a fallos en nodos distribuídos con **Apache Cassandra**.
* Despliegue de entornos **Ubuntu Server** y **Windows Server** en máquinas virtuales con configuración manual de interfaces de red e IPs.
* **Tecnologías:** Apache Cassandra, Docker, VirtualBox, Linux.
